Этот файл — передача контекста из чата с Claude. Прочитай его целиком перед работой.

## Что это
Приложение для студентов Cyprus International University (CIU, Северный Кипр) в духе Globi:
студенты одного вуза создают активности (футбол, учёба, ужин, поездка), другие присоединяются,
и у всех участников появляется общий групповой чат.

Автор — Khaiem, студент 2 курса Computer Engineering в CIU. Общается по-русски, коротко и прямо.
Хочет, чтобы ты сам принимал решения и отдавал рабочий код, а не задавал лишние вопросы.

## Что есть в прототипе (сохранить при переносе)
- Шапка: логотип CIU + слово «hangout», кнопка Create.
- Лента активностей как расписание: группы по дням (Today, Tomorrow, дата), слева крупное время.
- Строка активности: название, категория, место, аватарки участников, «N spots left»
  (оранжевым, когда осталось ≤2), Full при заполнении, кнопка Join прямо в ленте.
- Категории-фильтры: Sports, Food, Study, Games, Trips, Chill.
- Создание активности: название, категория, дата, время (нельзя в прошлом), место,
  лимит людей (или без лимита), детали. Создатель = хост и первый участник.
- Join → сразу открывается групповой чат этой активности. Leave → выход из чата.
- Вкладки внизу: Activities / Chats / Profile.
- Chats: список чатов всех активностей, где ты участник, сортировка по последнему сообщению.
- Профиль: фото, имя и фамилия, **Student ID (6–10 цифр, виден только владельцу)**,
  факультет, курс, «о себе», счётчики Going / Hosting, ближайшие планы, редактирование, выход.
- Карточка другого человека: имя, факультет, курс, bio — без Student ID.
- Интерфейс на английском (аудитория интернациональная).

## Что сделать (по приоритету)
Сделано: 1 (перенос), 2 (Firebase, транзакции, правила; фото — data URL 256px в профиле),
3 (Google Auth + обязательный профиль), 4 (Report, коллекция `reports`, раздел модерации в Profile
для custom claim `admin`, `scripts/set-admin.mjs`), 6 (хост редактирует/удаляет, прошедшие скрываются
через 2 часа). Осталось: ограничение входа доменом почты CIU, пуши (5).

1. **Перенести прототип в этот Vite-проект** вместо старого UI в `src/`, разбив на компоненты.
   Tailwind подключить нормально (сейчас в прототипе классы Tailwind).
2. **Firebase**: Auth + Firestore с реалтаймом.
   - `users/{uid}`: name, short (имя), dept, year, bio, photoURL. Student ID хранить отдельно
     (`users_private/{uid}`), читать может только владелец.
   - `activities/{id}`: title, cat, at, place, max, desc, hostUid, memberUids[], createdAt.
   - `activities/{id}/messages/{id}`: uid, text, createdAt. Читать/писать могут только участники.
   - Вступление/выход через транзакцию, чтобы не превысить лимит мест.
   - Security rules под всё это. Фото — Cloudinary или Storage (у автора нет Blaze-плана,
     в другом проекте он выбрал Cloudinary).
3. **Вход только для студентов CIU**: в идеале по университетской почте (домен уточняется
   на встрече). Пока — Google Auth + обязательное заполнение профиля.
4. **Модерация**: «Report» на активность и пользователя, коллекция `reports`, простая админка
   (роль через custom claim `admin`).
5. Пуш-уведомления «кто-то присоединился» / новые сообщения — после базовой версии.
6. Удаление/редактирование своей активности хостом, автоскрытие прошедших.
